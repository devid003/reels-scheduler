One-time setup

{{ 'Do these once. After that, tap Connect.' if not ready else ('Almost there: tap Connect above.' if not accounts else 'Done. Open again if you need the steps.') }}
  1. On developers.facebook.com, tap My Apps, then Create App. Pick the use case Manage everything on your Page.
  2. In the app, open Facebook Login settings and add this to Valid OAuth Redirect URIs:
    {{ redirect_uri }}
  3. In App settings, then Basic, fill in:
    Privacy Policy URL {{ site }}/privacy
    User data deletion {{ site }}/data-deletion
    Add an app icon and a category, then save.
  4. Still in Basic, copy the App ID and App secret. On Render, add them as FB_APP_ID and FB_APP_SECRET.
  5. Switch the app from Development to Live (the switch at the top of the app dashboard). Important: while it's in Development, only you can see the Reels it posts.
  6. Every other Facebook account you'll connect needs a role on the app: in App roles, add it as a Tester, then accept the invite from that account.

If Facebook shows an error about permissions when you connect, open Facebook Login for Business, then Configurations, create one with pages_show_list, pages_read_engagement and pages_manage_posts, and add its ID on Render as FB_CONFIG_ID.
